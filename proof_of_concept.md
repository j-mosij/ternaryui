# Proof of Concept: Ternary Core-Shell Metamaterial & PQC Security Engine

## Overview
`ternaryui` is an experimental serverless browser interface designed to model, simulate, and sonify active core-shell liquid-metal metamaterials (specifically **Copper-Gallium** transition-metal/liquid-metal matrices) using balanced ternary arithmetic, 5-trit tryte compression, and post-quantum cryptographic hardening.

## Core Pillars
1. **Material Physics Simulation:** Real-time geometric modeling of triple-toric liquid-shell matrices enclosing solid copper cores undergoing intermetallic phase expansion and capillary effervescence.
2. **Tryte-x5 Math Engine:** Compresses continuous floating-point spatial data streams into 5-trit undecimal ($3^5 = 243$ states) tensor representations for lightweight mathematical GPU-style client execution.
3. **Web Audio Sonification:** Maps transient fluid viscosity and phase volume expansion into microtonal frequency sweeps using the Web Audio API.
4. **Side-Channel & PQC Security:** Implements anti-cloning canvas fingerprinting, asynchronous `Float64Array` heap jitter masking against RAM/EM frequency extraction, and simulated post-quantum session key encapsulation.
