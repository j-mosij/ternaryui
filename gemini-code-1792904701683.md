# Ternary Metamaterial Loom Weaver (`ternaryui`)

[![License: CC-BY-4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)
[![Author](https://img.shields.io/badge/Author-j--mosij-blue)](https://github.com/j-mosij)

A zero-dependency, single-file serverless web application and visualization dashboard for active core-shell liquid-metal metamaterials.

## Features
- **Triple Toric & Möbius-Klein Topology:** Real-time canvas rendering of copper-gallium core-shell lattice structures.
- **Tryte-x5 Tensor Processing:** Balanced ternary data compression mapping floating-point coordinates into 5-trit undecimal states.
- **Web Audio Sonification:** Live audio feedback loop driven by effervescence and viscosity telemetry.
- **Post-Quantum Security Wrappers:** Built-in defenses against MITM, key cloning, serial tampering, and RAM/EM frequency side-channel analysis.
- **DOM Sanitization:** Strict input/output purification via DOMPurify.
